# AI 对话权限和费用控制

用户界面统一使用“行影集 AI 助手”。以下是部署者和开发者的内部运行说明。

## 访问和内容边界

登录用户只能访问自己提交的需求对话。匿名用户必须持有本需求的编辑回执或已验证邮箱的专用讨论链接；公开需求不代表公开对话。管理员可以独立讨论方案/补丁，普通用户不能提交这些模式。管理端 AI 使用看板允许管理员查阅已保存的需求对话，查看详情会记录在审计日志中。后台执行时再次检查角色和账号状态。邮箱讨论链接不能授权编辑、任务执行或管理操作；退订及重新订阅轮换版本，使旧链接失效。

入口先用本地规则拒绝明显越界或注入指令，拒绝也计入发送次数，但不排队调用模型。系统提示限定行影集，并将全部需求、历史、日志和代码标记为不可信资料。规则过滤和模型提示不能保证识别所有语义绕过，权限边界由独立运行容器、只读资料卷和服务端鉴权执行。DSH 使用官方原生文件读写、搜索、目录切换与 Bash 工具，在一次性工作区内分析；可以生成临时补丁，不修改公开源码卷或线上应用。平台数据库、上传文件、邮件/GitHub/真实模型凭证、宿主目录和 Docker socket 不进入该容器。不加载个人插件、遥测或会话日志插件。

## 默认配额

| 范围 | 限额 |
| --- | --- |
| 匿名讨论身份 | 每天 10 次 |
| 登录用户（包括管理员） | 每天 30 次 |
| 来源 IP | 每天 60 次 |
| 全站对话发送 | 每天 200 次 |
| 同一身份发送间隔 | 20 秒 |
| 单个对话 | 100 条消息，最多 1 个未完成请求 |
| 全站付费模型请求（包含后台分诊和管理员连接测试） | 每天 200 次 |
| 全站 token 保守预留预算 | 每天 1,000,000 |
| 单次输出 | 2,048 tokens，可配置范围 256–4,096 |
| 模型并发 | 全站 1 个 |

`RP_AI_*` 环境变量对应上述配额，值为零时关闭对应预算。身份、IP、全局计数在共享 SQLite 中以条件更新原子扣减，不依赖单进程内存。每日额度在 UTC 零点重置。IP 只使用服务器连接地址，不自行信任客户端 `X-Forwarded-For`。反向代理未配置可信地址时用户会共享代理的 IP 配额，限制更保守；不要把 Uvicorn 的可信代理配置设为 `*`，需仅信任实际受控代理。

发送和手动重试都扣次数；幂等回执重放不重复扣次数。会话失败不自动调用模型重试。历史仅取 4 轮并截断；每条用户消息最多 2,000 字，序列化输入最多 24KB。超长资料失败并提示精简。

全部 AI 入口每次分析（含模型故障切换）共用最多 12 次模型请求和约 100 秒上限。网关验证每次运行的独立凭证，允许官方原生文件/搜索/命令工具名称，限制请求 128KB、响应 256KB、输出 tokens，并阻断额外请求和 SDK 自动重试；实际发出前，以请求 UTF-8 字节数加输出上限预留 token 额度，失败不退额度。预留值不是账单中的实际 tokens；实际金额仍由模型价格和供应商计费规则决定。全局模型锁带超时和租约版本校验。

旧匿名实时预分析接口返回 410，不调用模型。邮件订阅也限制单需求 3 个地址、单邮箱每天 3 次确认申请、全站每天 100 次确认申请；投递尝试限制单邮箱每天 20 次、全站每天 1,000 次。

新建单前的 `/api/intake/messages` 使用相同的身份、IP、全站和模型额度，不恢复旧预分析接口。模型返回严格校验的回复和需求草稿；用户核对后才通过标准需求接口提交。多轮历史只在当前标签页保留，服务端签名绑定用户或匿名讨论凭证并限制为一天，不能换用户重用或篡改；签名不是加密，讨论凭证不得公开分享。助手、后台分诊和需求讨论都能自主读取固定公共仓库最新正式 Release 的真实文本文件及官网文档，不经过自建检索索引。文件清单仅作引用与版本映射，在真实模型调用中加载。入口代理对写接口单独限频、限制请求体并设置有界超时。

Runner 只加入 Docker 内部网络，不发布端口；只访问 API/worker 的临时模型网关，不直连外网。监督进程持有内部调用凭证，每次 SDK 使用新的非 root UID 和清空的环境，无法读取监督进程凭证。单次网关令牌仅允许当前请求的有限模型轮次，不能访问平台 API。根文件系统与公开资料只读，`/tmp` 为 256MiB 临时盘，内存 768MiB、CPU 1 核、进程 128 个；请求结束或超时杀死该 UID 的所有子进程并清理工作区。Docker 隔离仍依赖正常维护的宿主内核与 Docker 配置。

## 入口防护与部署

Nginx 限制 API 频率、对话写请求频率、单 IP 连接数、请求体大小及慢请求超时；读取对话不会消耗写入频率。生产 Compose 仅将网页绑定到主机回环地址，API、MCP 和数据库保持私有网络。不要直接公开 API 端口。多实例必须共享同一数据卷，SQLite 不适用于跨主机分布式配额；需要扩容时先迁移到集中式配额存储。

这些限制用于约束应用和模型开销。公网流量攻击仍需入口反向代理、CDN/WAF 或主机网络层限流；不可将应用配额描述为能够消除所有 DDoS 风险。上线后同时设置供应商账户硬额度和账单告警。

## 模型用量与故障切换

管理员在 AI 设置按 M（百万 Token）调整额度，支持三位小数；后端仍用整数 Token 保存，不改变已有策略及计数。管理端「AI 用量」的模型面板按模型和 API 连接汇总最近 30 天调用、失败、输入、输出、今日合计与额度预留。实际统计来自 Messages JSON/SSE 的 usage（缓存输入计入输入），累计流式输出取最终最大值，不重复累加。缺失 usage 明确标为未完整上报，不拿额度预留冒充账单。统计保存模型标识、用量、状态、时间及内部会话关联 ID，不额外保存请求正文、密钥或用户身份。新版 AI 助手单独保存用户输入的文字、助手回复、附件数量及处理状态，正文仅管理员可查阅且访问有审计。不会额外保存附件文件名、原文件、签名状态或访问凭证。旧部署未记录的文字问答无法回溯。

模型或连接不可用时，按任务路由的前三个启用模型依次尝试，可跨 API；所有尝试共享 12 次模型请求和整体时限。每次上游尝试独立扣预算并记录用量；平台额度或频率拒绝立即停止，不能通过切换绕过。连接测试仅检查指定模型，不切换。SDK 的隐式模型重试禁用。

运营看板在对话准入时记录按密钥散列的去重标识、来源、会话 ID、时间及是否重试，不保存 IP、聊天原文、附件或身份映射，接口只返回汇总值。图片由浏览器压缩，服务端限量校验；图片仅由模型网关转发给管理员标记支持视觉输入的 Messages 模型，不写入运行容器的工作区。文本附件作为不受信任的资料参与当前轮分析，不写入签名状态；请勿上传含凭证或个人信息的文件。
